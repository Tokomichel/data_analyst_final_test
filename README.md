### Bonjour,

<p>
Veuillez trouver en pièce jointe le tableau complété, ainsi que le script Python utilisé pour automatiser la collecte des informations demandées.
</p>

<p>
Après avoir étudié plusieurs approches, il m'a semblé que l'utilisation d'API spécialisées constituait la solution la plus pertinente. Cependant, la plupart de ces API sont payantes ou nécessitent des procédures d'inscription et de configuration relativement longues avant de pouvoir être exploitées.
</p>

<p>
J'ai donc choisi d'utiliser une solution automatisée basée sur une app IA capable d'effectuer des recherches sur le Web et d'extraire les informations demandées (nom du CEO, lien LinkedIn et pays de l'entreprise). Cette approche m'a permis d'automatiser efficacement le traitement des données.

Son principal inconvénient est que certaines informations ne sont pas toujours disponibles publiquement, en particulier le lien LinkedIn de certains CEO. Dans ces cas, le champ correspondant a été remplacer par "None"</p>
